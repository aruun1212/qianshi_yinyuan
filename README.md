# 测试前世姻缘

一款**单文件 HTML 中式微恐怖游戏**，伪装成一个「前世姻缘测试」，实为港式冥婚题材的规则怪谈体验。

零框架、零构建、零外部库——一个 `index.html` 打开即玩。

**▶ 在线体验：https://qianshiyinyuan.netlify.app/**

> ⚠️ 含惊吓（jump scare）与恐怖元素，心脏不适者慎玩。仅供娱乐。
